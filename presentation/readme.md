# Introducing Fantail

A short presentation introducing Fantail: worker-aware HTTP load balancing with a global admission queue.

The deck explains the scheduling problem Fantail addresses, its permit and queue model, and how it compares with a shared-listener baseline under a representative CPU-heavy workload.

## Setup

```bash
$ bundle install
```

## Running

```bash
$ bundle exec presently
```

Then open <http://localhost:9292> in your browser.

Use the **arrow keys** (or swipe) to navigate between slides.

For presenter notes, visit <http://localhost:9292/presenter>.
